# YesWeHack Program to Markdown Bookmarklet

Bookmarklet that exports a YesWeHack program page as Markdown.

## Install

Open `install.html` and drag the link to your bookmarks bar, or create a bookmark whose URL is the content of `bookmarklet.txt`.

## Usage

On a `https://yeswehack.com/programs/<slug>` page, click the bookmark. Click it again (or press Escape) to close.
